# FUTURE_ML_02

## Future Interns - Machine Learning Internship

### Task 2 - Support Ticket Classification

## Objective

To build a machine learning system that automatically classifies customer support tickets and assigns priority levels.

## Dataset

TriageIQ Customer Support Ticket Dataset from Hugging Face.

The dataset is synthetic and was used for educational and project purposes.

## Technologies

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Text Processing

- Text cleaning
- Tokenization
- TF-IDF feature extraction

## Machine Learning

Logistic Regression was used for:

- Ticket category classification
- Urgency classification

## Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Output

The system predicts:

- Ticket category
- Ticket urgency: High / Medium / Low
